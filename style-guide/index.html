    About this site/Design Components

    Design Components

    Every building block used on this site, on one page — the palette, type, buttons, cards, schedules, people, events, FAQs, forms and more.

    In this section

    • Site Guide for Parish Staff
    • Design Components
    • Photo Credits

    Each component below is a WordPress block (a Group, Columns, Image, List or Buttons block) with a small amount of styling. The office never needs to know that; it simply edits text and pictures. Developers can find the class names in assets/site.css.

    Colours

    Navy#1c2b4b · header, buttons
    Gold#b8933f · accents
    Ivory#f7f3ec · page background
    Sand#ece5d7 · alternate bands

    Typography

    Cormorant Garamond for headings and Source Sans 3 for text — both free Google Fonts available in WordPress.com's font library. Body text is 17px on desktop and 16px on phones with generous line height; paragraphs are limited to about 75 characters per line for comfortable reading.

    Image and text columns

    Media row

    Image beside text

    The workhorse layout for ministry and sacrament pages. On phones the image stacks above the text. Add media-row--flip to put the image on the right.

    Button

    Steps, info boxes and FAQs

    1. Numbered step

      Used for processes such as booking a baptism or preparing for marriage.

    2. Second step

      Each step can hold a heading and a short paragraph.

    Info box

    A highlighted note with a gold rule — good for "what to bring" and deadlines.

    Dark info box

    For emergency contacts and important notices.

    What is a FAQ block?

    A question that opens on click. It works without JavaScript and is a standard WordPress Details block.

    Can several be stacked?

    Yes — most sacrament and ministry pages end with three or four of them.
